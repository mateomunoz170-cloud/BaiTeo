# Portal de Alumnos - C.E.T. N° 1

Este proyecto es una plataforma web desarrollada para la comunidad educativa del **C.E.T. N° 1**. Incluye un portal para trámites escolares y un foro interactivo de novedades.

---

## 🚀 Funcionalidades
* **Trámites de Alumnos:** Formularios para inscripción a mesas de examen, solicitud de analítico incompleto y analítico final de carrera.
* **Trámites de Docentes:** Renuncia, licencias, etc.
* **Foro Estudiantil:** Sección de comentarios con sistema de actualización de "likes" en tiempo real.
* **Navegación Dinámica:** Estructura de rutas limpias y estandarizadas.

---

## 🛠️ Tecnologías Utilizadas
* **Front-end:** HTML5, CSS3, JavaScript.
* **Back-end:** PHP.
* **Base de Datos:** MySQL / MariaDB.
